The early archive contains game-making demonstrations as well as later
[game reviews and gameplay](/wiki/events/gaming-and-review-videos/). These
examples expand the title-level sequence in the
[2015 source catalogue](/wiki/archive/2015-source-catalog/) with observations

commercial publication or a completed game.

## October 2015: redesigning a Space Invaders-style project

The source labelled *Creating space invaders game on XCODE 7 macbook air*
visibly alternates between code and interface design. At **00:01:20**, Xcode
shows movement and projectile-related code. At **00:05:31**, the storyboard
contains a ship graphic, a projectile and start/shoot controls on an orange
background. At **00:10:43**, a browser displays a pixel-art image search;
at **00:15:04**, the project view has a star-field background behind the ship.
This is a visible asset-and-interface revision sequence, not evidence that all
the code or artwork was created from scratch or licensed for redistribution.

## December 2015: two platformer lessons

The **part 1** recording starts with a mostly empty storyboard in the
**00:00:52** sample. At **00:03:36**, an Objective-C header is being edited;
at **00:06:59**, the storyboard contains a small coloured rectangle above a
matching floor strip and a **jump** control. The **00:09:49** sample shows
jump/falling-related code. The frames substantiate a simple platformer
construction lesson, but do not test whether its physics or code are correct.

The separately preserved **part 2 movement** continues the same-looking
rectangle-and-floor interface. At **00:00:42**, a **left** control is being
named; **00:02:55** shows a movement-timer code edit. The **00:05:40** simulator
view includes **left**, **right** and **jump** controls; **00:07:58** returns to
the storyboard and its button-event connections. Together with the two part
labels, those shared visual elements establish a connected tutorial pair,
not merely two unrelated programming titles.

## Relationship to the later HIMR game

The [Kent/Maidstone-era article](/wiki/eras/kent-maidstone-era/#epilogue-the-2022-himr-game-project)
separately documents the 2022 Patreon game-project posts. That later account
should not be read as proof that these 2015 projects became the same game or
that development continued without interruption. Likewise, the
[drawing and painting videos](/wiki/events/drawing-and-painting-videos/) are
a separate recurring creative format, not evidence that every game asset
originated in Daniel's own artwork.
