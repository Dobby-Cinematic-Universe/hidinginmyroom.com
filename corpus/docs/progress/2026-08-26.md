# 2026-08-26 foundation milestone

- Added standard-library Python package and checksummed SQLite migration runner.
- Added durable source, recording, media, run, transcript, multimodal observation,
  confidence calibration, entity, event, review, claim-link, and publication models.
- Added metadata-only importers for preserved Archive.org metadata, the legacy source
  manifest, and the current YouTube channel inventory.
- Added private discovery lanes for arbitrary Archive.org items, yt-dlp search rows,
  bulk validated yt-dlp info JSON, Archive.org URL hints, and torrent file manifests.
- Added deny-by-default deterministic v1 export plus the v2 content-addressed
  manifest/catalog/recording shard exporter and strict full-tree validation.
- Scoped automated metadata publication to three reviewed Archive.org items and the
  captured public official-channel inventory; third-party discovery stays withheld.
- Confirmed that legacy machine summaries and speaker guesses are omitted and that
  no legacy transcript revisions are created.

Initial private catalog: 10,821 sources, 2,513 recordings, 5,711 source/recording
links, 5,901 source snapshots, 299 open review tasks, and zero transcript revisions.
It includes metadata for 3,545 Archive.org video files, 50 validated yt-dlp search
captures, 4,719 torrent file candidates (manifest only; zero payload bytes acquired),
and 731 Archive.org coverage hints. The original 2,463-record metadata projection was
a pre-gate fixture and is no longer active. The clean current catalog has no explicit
publication or gate decisions, so checked-in v2 release
`release_c1cb78c355b5b7d6dd6dd852` contains zero recordings, sources, revisions, or
segments.

Next milestone: acquisition ledger population, media probing/fingerprinting, a small
